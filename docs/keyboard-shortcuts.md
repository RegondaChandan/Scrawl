# Keyboard shortcuts

Scrawl uses the Command key on macOS and Control on Windows and Linux.

## Tools

| Key | Tool          |
| --- | ------------- |
| `V` | Select        |
| `H` | Pan           |
| `R` | Rectangle     |
| `O` | Ellipse       |
| `D` | Diamond       |
| `A` | Arrow         |
| `L` | Line          |
| `P` | Freehand draw |
| `T` | Text          |
| `N` | Note          |
| `E` | Eraser        |

## Editing

| Shortcut                             | Action                             |
| ------------------------------------ | ---------------------------------- |
| `Command/Control + Z`                | Undo                               |
| `Shift + Command/Control + Z`        | Redo                               |
| `Command/Control + K`                | Open the command menu              |
| `Command/Control + A`                | Select all unlocked objects        |
| `Command/Control + C`, `X`, `V`      | Copy, cut, and paste objects       |
| `Command/Control + D`                | Duplicate selection                |
| `Command/Control + G`                | Group selection                    |
| `Shift + Command/Control + G`        | Ungroup selection                  |
| `Command/Control + [` or `]`         | Move backward or forward           |
| `Shift + Command/Control + [` or `]` | Send to back or bring to front     |
| Arrow keys                           | Move selection by one canvas unit  |
| `Shift` + Arrow keys                 | Move selection by ten canvas units |
| `Delete` or `Backspace`              | Delete selection                   |
| `Shift` while resizing               | Preserve the selection proportions |
| `Shift` while rotating               | Snap rotation to 15-degree steps   |
| `Alt` while moving or resizing       | Temporarily disable smart guides   |
| `Command/Control + Enter`            | Finish inline text editing         |
| `Escape`                             | Cancel the current interaction     |

## Pages

| Shortcut                    | Action                                |
| --------------------------- | ------------------------------------- |
| `F2`                        | Rename the focused page               |
| `Alt + Shift + Arrow Left`  | Move the focused page one place left  |
| `Alt + Shift + Arrow Right` | Move the focused page one place right |

Pages can also be reordered by dragging their tabs. Deleting a non-empty page asks for
confirmation, and the last remaining page cannot be deleted.
